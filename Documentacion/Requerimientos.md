# RUMBO JOVEN

## Levantamiento de requerimientos

**Asignatura:** Programación 1  
**Estudiante:** Escribe aquí tu nombre  
**Lenguaje:** Java

### 1. Introducción

Rumbo Joven es una empresa de viajes ficticia. El proyecto consiste en crear un programa en Java que permita registrar clientes, seleccionar el tipo de maleta, registrar acompañantes, calcular el valor del viaje, visualizar la información y guardar un respaldo en un archivo de texto.

### 2. Objetivo general

Desarrollar un programa en Java que permita registrar la información de los clientes y calcular el valor de sus viajes de forma sencilla.

### 3. Requerimientos funcionales

- **RF01:** Registrar el nombre, la cédula, la fecha del viaje y el destino del cliente.
- **RF02:** Permitir seleccionar una maleta básica (MB) o premium (MP).
- **RF03:** Registrar la cantidad de acompañantes.
- **RF04:** Calcular el valor del viaje.
- **RF05:** Mostrar toda la información registrada.
- **RF06:** Guardar un respaldo en un archivo TXT.
- **RF07:** Mostrar un menú con las opciones del programa.
- **RF08:** Permitir salir del programa.

### 4. Requerimientos no funcionales

- **RNF01:** El programa debe desarrollarse en Java.
- **RNF02:** La interfaz debe ser sencilla y funcionar en la consola.
- **RNF03:** El programa debe validar los datos ingresados.
- **RNF04:** El código debe estar organizado y comentado.
- **RNF05:** El archivo de respaldo debe ser fácil de leer.

### 5. Reglas del negocio

- La maleta básica (MB) cuesta $285.325 COP.
- La maleta premium (MP) cuesta $325.650 COP.
- El sistema debe permitir ingresar la cantidad de acompañantes.
- El valor del viaje se calcula multiplicando el precio de la maleta por la cantidad de acompañantes.
- La información registrada debe poder visualizarse y guardarse en un archivo TXT.

### 6. Menú principal

1. Registrar cliente.
2. Tipo de maleta.
3. Registrar acompañantes.
4. Valor del viaje.
5. Visualizar toda la información.
6. Respaldo TXT.
7. Salir.

### 7. Resultado esperado

Obtener un programa en Java que permita registrar clientes, calcular el valor de sus viajes, consultar la información y guardar un respaldo de los datos.
