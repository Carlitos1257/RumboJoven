# Rumbo Joven

**Proyecto de Programación 1 — Java**

## Descripción
Rumbo Joven es un programa de consola para registrar clientes de una agencia de viajes, seleccionar el tipo de maleta, registrar acompañantes, calcular el valor del viaje y guardar un respaldo en un archivo TXT.

## Tipos de maleta
- **MB:** Maleta básica — $285.325 COP.
- **MP:** Maleta premium — $325.650 COP.

## Opciones del menú
1. Registrar cliente.
2. Seleccionar tipo de maleta.
3. Registrar acompañantes.
4. Calcular valor del viaje.
5. Visualizar información.
6. Guardar respaldo TXT.
7. Salir.

## Tecnologías
- Java
- Visual Studio Code

## Ejecución
Desde la carpeta principal del proyecto, abre la terminal y ejecuta:

```powershell
java source/RumboJoven.java
```
